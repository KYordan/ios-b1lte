# Flash kit — Backup and flashing of iOS images on Galaxy S10 (SM-G973F)

## Contents

| File | Role |
|---------|------|
| `check-device.sh` | Checks that the phone is in TWRP, rooted, model SM-G973F, and lists the target partitions |
| `backup-partitions.sh` | Backs up the important partitions before any change |
| `flash-images.sh` | Flashes boot.img, system.img and userdata.img into the existing partitions |
| `images/` | Folder where the 3 images (boot.img, system.img, userdata.img) go |
| `docs/partition-map.md` | Map of the S10 partitions and what must NEVER be written |

## Prerequisites

- Phone in **TWRP 3.7.1** with root ADB
- Phone serial: `<SERIAL>`
- `adb` available: `~/Developer/android/platform-tools/adb`
- Build Mac: ThinkPad T470s, macOS 26

## ⚠️ Safety rules (non-negotiable)

1. **Only write** BOOT (`sda14`), SYSTEM (`sda25`) and USERDATA (`sda34`).
2. **NEVER write**: `bota*`, `efs`, `sec_efs`, `cpefs`, `radio`, `keystorage`, `keydata`, `keyrefuge`, `param`, `up_param`, `uh`, `uhcfg`, `steady`, `persistent`, `misc`, `recovery`, `dtb`, `dtbo`, `vbmeta`, the GPT.
3. **Before each write**: check TWRP, root, `ro.boot.em.model = SM-G973F`, by-name path, exact size, partition not mounted, SHA-256 hash, read-back after writing.
4. **Backup mandatory** before any flash: use `backup-partitions.sh`.
5. This kit does **not repartition** the phone. Repartitioning a Samsung S10 is done with Odin + a PIT file; it is a separate operation and very risky.

## How to get the 3 images

| Image | How to get it |
|-------|-------------------|
| `boot.img` | `scripts/package-boot.py` in `beyond2lte-ios/` (produces `out/b1l-metal-NNNN/boot.img`) |
| `system.img` | `b1l-tools/build-system-image.sh` (contains the native cache + log) |
| `userdata.img` | `b1l-tools/build-ios-root.sh` from the iOS 26 IPSW `23G90` (iPhone 16 Pro Max) |

Then place them in `flash-kit/images/` with the exact names: `boot.img`, `system.img`, `userdata.img`.

## Recommended order of use

1. `./check-device.sh` — check the state of the phone
2. `./backup-partitions.sh` — back up everything before touching anything
3. Place the images in `images/`
4. `./flash-images.sh` — flash the 3 images (with guards and read-back)
5. `adb reboot` — restart into iOS

## `images/` folder

Empty by default. It is up to you to put the 3 images generated by the build chain there. Do not commit the images (too large, potentially containing personal data).
